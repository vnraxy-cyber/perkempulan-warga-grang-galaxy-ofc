# Grand Galaxy City — HTML/CSS/JS

Website responsive yang dibuat berdasarkan mockup 12 halaman yang kamu kirim.

## Halaman
1. Beranda / Home
2. Tentang Kami
3. Kawasan Kami
4. Detail Cluster (Cluster Galaxy)
5. Fasilitas
6. Tips & Informasi Hunian
7. Galeri
8. Berita & Promo
9. Event
10. Kontak Kami
11. 404 Not Found
12. Coming Soon

Tambahan: halaman artikel untuk contoh detail konten.

## Cara menjalankan
Tidak perlu framework atau build tool.

1. Extract ZIP.
2. Buka `index.html` di browser.
3. Navigasi halaman menggunakan menu.

## Catatan
- Semua struktur dibuat dengan HTML, CSS, dan JavaScript vanilla.
- Data cluster, fasilitas, berita, event, dan kontak berada di `script.js` sehingga mudah diedit.
- Foto memakai URL gambar dari Unsplash agar tampilan langsung terisi.
- Map pada mockup dibuat sebagai ilustrasi CSS, bukan peta interaktif.
- Desain dibuat responsif untuk desktop, tablet, dan HP.
